# 固定的颜色证据

这些文件仅供开发、溯源与离线重建。安装和使用插件不需要下载或读取它们。

- `jetbrains/`：公开 IntelliJ Community `idea/262.10968.63` 颜色资源，与本机 IDEA 安装包逐字节一致；保留原始内容。
- `gerry-islandsDarcula.theme.json`：Gerry 的第三方参考原文，不是官方导出。
- `openidea-token-groups.json`：官方 `themeTokenGroups(tokens.css)` 输出；Islands Dark 值仅记录 fallback。
- `openidea-mapping.json`：官方 `intellijTheme.ts` 导出的三张原始映射表。
- `UPSTREAM.json`：固定 commit、文件路径、公开链接和 SHA-256。
- `token-provenance.json`：本项目生成的逐 Token 来源、近似状态及宿主继承记录。
